- **Design:** UI/UX, web and graphic design, cross-browser implementation
- **Platforms & operations:** ASP.NET, WordPress, AWS, hosting, SEO, analytics
- **Education:** B.Sc. in Computer Engineering — AAST, Egypt
- **Based in:** Kuwait
